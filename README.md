# Arabic Speech Dataset - 10+ hours
Dataset comprises over **10 hours** of audio featuring **20+ native speakers** engaged in telephone-quality dialogues in the Arabic language. It contains high-quality speech data designed for training robust **language models** and **automatic speech recognition** systems in real-world conversational scenarios. - **[Get the data](https://unidata.pro/datasets/arabic-speech-recognition/?utm_source=github-nlp&utm_medium=referral&utm_campaign=arabic-speech-recognition)**
